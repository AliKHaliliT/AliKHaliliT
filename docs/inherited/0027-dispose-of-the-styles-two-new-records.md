# 0027. Dispose of the style's two new records

Status: Accepted
Date: 2026-09-24

## Context

The style moved four commits past the pin this project carried, and two of them bring
decision records, 0083 and 0084. The first answers the one entry this project's upstream
file held, that a child could not name a real term where the spelling advisory keeps its
ignore list, and the style's treasury disposed of that entry by keeping it. The second
widens the splice advisory to read a wrapped sentence whole. The other two commits are a
server seat's change and a merge, and carry nothing a client child holds. A re-alignment
writes a record of the child's own naming every record the inherited folder gained, with
what each bound here and what changed, and this is that record.

## Evidence

On the final tree the docs audit agreed with its conventions, printing the ledger's
review row as advice and naming the spelling advisory as not run, because codespell is
not installed on this machine and the workflow installs it. The selftest reported every
rule firing, and the lint, the type check, the suite, and the build passed.

A stand-in for the spelling advisory, codespell's own dictionaries over the carried
audit's skip list with the new term file read the way codespell reads it, named 22
candidates without the file and none with it. The four terms are MapPin, lucide's icon
component, whose name the dictionary reads as a misspelling of mapping, at 19 places;
Ines, a demo book's author; aer, the journal code inside a demo DOI; and theses, the
plural of thesis in the content schema.

## Options considered

- **Correct the four words instead.** Refused, because the icon's name is the library's
  export, a name and a DOI are data the record states, and theses is already spelled
  right.
- **Keep answering them in each commit message.** Refused by the style's 0083, since a
  term recurs on every run and a commit message answers one.

## Decision

Recopy the rulebook, the docs audit, and its selftest, re-pin all three in CI, and carry
the two records into the inherited folder. Name the term file in the guide's list of
advisories and in the baseline's trigger table, in the template's words, write this
project's four terms into it, and delete the upstream entry the style now carries,
moving the pin.

| Record | What it bound here |
| --- | --- |
| [0083, Keep a project's spelling terms in a file of its own](../inherited/0083-keep-a-project-s-spelling-terms-in-a-file-of-its-own.md) | The new `.codespellignore` with four terms, the baseline's trigger row, the guide's clause on the spelling advisory, and the recopied audit and selftest, which pass the file to codespell and prove a named term silent. The upstream entry that asked for it is deleted. |
| [0084, Read a paragraph, not a line, for the splice advisory](../inherited/0084-read-a-paragraph-not-a-line-for-the-splice-advisory.md) | The recopied audit's splice advisory, which now joins a record's prose blocks before it looks for a spliced colon. It ran over this record before main held it and named nothing. |

## Consequences

The spelling advisory stays silent about this project's own terms from this commit on,
and a new term enters the file in the change that brings it, as the baseline's other
conditional files do. The upstream file holds nothing open.
