Status: Accepted
Date: 2026-11-25

## Context

The template moved five commits past the pin this deployment carried, from ffb5586 to
078907d. One fills a star by the rating's fraction. The others carry the template's
re-alignment with its style, which split the guide and the rulebook into documents read
whole, moved the lint stack to ESLint 10, and rebuilt the workflow around a landing job,
along with the dependency fixes npm audit offered, pins taken from the bytes git stores,
and six British spellings made American. The inherited folder gains the template's
decision 0029, which disposes of the fifty-four records the style gained. A re-alignment
writes a record of the child's own naming every record the inherited folder gained, with
what it bound here and what changed, and this is that record.

## Evidence

The template's source, documents, scripts, workflow, and lint configuration came over byte
for byte wherever this deployment carried them unchanged. The baseline, the map, the
ledger, the manifest, and the state file were merged from the template's diff, keeping the
profile page's exception, the deployment's own rows, and its profile-art script. On the
final tree the docs audit, its selftest, the edition tool's selftest, the lint, the type
check, the suites, and the build passed.

## Options considered

- **Keep this deployment's short copy of the hard rules in its guide.** The rules would
  then live twice, once in the guide and once in the documents the template now reads
  whole, and the guide would stand past the bound on living documents. Refused.

## Decision

The template's changes are carried whole, as this deployment's decision 0006 requires.
The rules of the tree open with this deployment's own rule that the record is real, and
the guide keeps the profile page's exception and the two directions of the upstream
report. The two suites adapted to the real record stay, and the guide now names the shelf
suite beside the loader suite, so a later re-alignment leaves both in place.
