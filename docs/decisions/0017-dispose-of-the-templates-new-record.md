# 0017. Dispose of the template's new record

Status: Accepted
Date: 2026-09-24

## Context

The template moved one commit past the pin this deployment carried, a
re-alignment of its own to the style's commit a4b27eb, and the inherited folder
gains its decision 0027. That record disposes of the two records the style
gained there. The first gives a project its own spelling terms in a file of its
own, which answers the one entry this deployment's upstream file held, that a
deployment could not name a real word where the spelling advisory keeps its
ignore list. The second widens the splice advisory to read a wrapped sentence
whole. A re-alignment writes a record of the child's own naming every record
the inherited folder gained, with what it bound here and what changed, and this
is that record.

## Evidence

On the final tree the docs audit agreed with its conventions, printing the
ledger's review row as advice and naming the spelling advisory as not run,
because codespell is not installed on this machine and the workflow installs it.
The selftest reported every rule firing, and the lint, the type check, the
suite, and the build passed.

A stand-in for the spelling advisory, codespell's own dictionaries over the
carried audit's skip list with the new term file read the way codespell reads
it, named 21 candidates without the file and none with it. The three terms are
MapPin, lucide's icon component, whose name the dictionary reads as a
misspelling of mapping, at 19 places; Statics, a course in the record's
engineering degree; and theses, the plural of thesis in the content schema.

## Options considered

- **Take the template's own term file along with its other files.** Refused,
  because the file is a project's own list and is never recopied at
  re-alignment, and two of the template's four terms name demo content this
  deployment does not carry.
- **Keep the upstream entry open until the template writes back.** Refused,
  because the template now carries the file the entry asked for, and an entry
  the template carries is deleted with its form taken.

## Decision

The rulebook, the docs audit, and its selftest are recopied from the template
and re-pinned in CI with the template's workflow, and the inherited folder
gains the template's record. The guide's list of advisories and the baseline's
trigger table name the term file in the template's words, this deployment's
three terms go into it, and the upstream entry is deleted as the pin moves.

| Record | What it bound here |
| --- | --- |
| [the template's 0027, Dispose of the style's two new records](../inherited/0027-dispose-of-the-styles-two-new-records.md) | The new `.codespellignore` with three terms, the baseline's trigger row, the guide's clause on the spelling advisory, and the recopied audit and selftest, which pass the file to codespell, prove a named term silent, and read a record's prose in whole blocks for the splice advisory. The upstream entry that asked for the file is deleted. |

## Consequences

The spelling advisory stays silent about this deployment's own terms from this
commit on, and a new term enters the file in the change that brings it. The
upstream file holds nothing open.
