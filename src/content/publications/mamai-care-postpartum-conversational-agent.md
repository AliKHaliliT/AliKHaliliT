A retrieval-augmented conversational agent for postpartum maternal health support, grounded in a curated 14-source knowledge base and carrying each mother's context across sessions in a persistent memory. Across 600 graded responses and four large language model backbones, retrieval brought factual grounding up to 96%, and session memory restored the personal relevance that retrieval alone can lose on questions that depend on a mother's own history.
