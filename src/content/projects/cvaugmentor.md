A Python package for augmenting images and videos, making it easier to enhance and modify visual data for computer vision tasks. It offers fourteen augmentations, including blur, brightness, cutout, exposure, flip, grayscale, hue, negative, noise, rotate, saturation, shear, and zoom, all composable through a simple Pipeline API. The package is published on PyPI and installable with pip, with documentation automatically regenerated by a GitHub Actions workflow and hosted at alikhalilit.github.io/CVAugmentor.
