A large-scale dataset of 75,000 rice grain images spanning five rice varieties, annotated for both object detection and object segmentation. The original classification images published by Murat Koklu on Kaggle were extended with a custom automatic annotator script written in Python, producing LabelMe JSON annotations that also embed the encoded image data. Both the detection and segmentation versions are published on Kaggle, and the annotations were validated with small-scale YOLOv5 training runs plus real-world inference on 16MP phone-camera photos of Thai white rice.
