A lightweight, performant, and customizable generator for animated analog TV static built with HTML Canvas and modern JavaScript. Visual frames are pre-computed and driven through requestAnimationFrame for a smooth, CPU-friendly loop, while an optional synchronized static hiss is synthesized in real time with the Web Audio API via a non-blocking AudioWorklet. Effects range from fine-grained grayscale fuzz to coarse, colorful snow and are defined as simple configuration objects consumed by a central factory module. A live demo is hosted on GitHub Pages.
