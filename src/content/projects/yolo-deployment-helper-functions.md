A set of helper functions for preprocessing, postprocessing, and deploying YOLO segmentation models in real-world inference pipelines. It provides letterbox resizing that preserves aspect ratio, utilities for rescaling bounding boxes and masks from padded coordinates back to the original image, and end-to-end processing of ONNX or PyTorch model outputs. The repository accompanies my Medium guide on taking YOLO from raw outputs to optimized deployment.
