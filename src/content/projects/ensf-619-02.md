Coursework repository for ENSF 619 02, a Geo AI course. It stores lab code such as a geospatial data ingestion pipeline that performs API-based downloads of USGS GeoJSON data and Natural Earth coastline archives, then reports file sizes, feature counts, and bounding box CRS information to the console. The scripts intentionally rely on plain Python and the requests library, with no specialized geospatial dependencies, so they run easily on any machine.
