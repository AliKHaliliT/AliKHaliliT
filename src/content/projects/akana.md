A React Native application developed as part of my master's thesis, serving as the user interface for an agricultural lameness detection system and laying the groundwork for a broader farmer companion app. It features deep linking, secure credential storage via react-native-keychain, a full caching system for hybrid online and offline operation, and a library of reusable, documented components. The app integrates with the EtugenEke FastAPI backend, and its name means The White Mother in Turkic culture.
