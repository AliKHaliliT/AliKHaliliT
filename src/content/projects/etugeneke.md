A modern, secure, and modular backend server built with FastAPI as a core component of my master's thesis, powering the AkAna companion mobile application. It exposes a full RESTful API covering authentication, tokenized password reset with deep linking, device-aware redirection between mobile app and web, file and video upload handling, and an SQLAdmin-based admin interface. The stack pairs FastAPI and Uvicorn with SQLAlchemy, Pydantic, and SQLite, emphasizing clean architecture, scalability, and extensibility.
