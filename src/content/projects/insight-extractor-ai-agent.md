A model-agnostic document analysis system that extracts structured insights from documents of various formats, returning consistent JSON AnalysisReport objects covering thematic, code, quantitative, sentiment, and table insights. It pairs a FastAPI backend powered by the pydantic-ai agent framework with a modern HTML, CSS, and vanilla JavaScript UI, and supports multiple LLM providers including OpenAI, Anthropic, and Google. A rate-limited working demo is hosted on Render at insight-extractor-ai-agent.onrender.com.
