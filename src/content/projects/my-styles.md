A curated collection of custom software engineering templates, architectural blueprints, and boilerplate designs built to enforce clean execution and reliable human-AI collaboration. It currently ships ArchetypeCore, a highly structured, framework-agnostic backend template that enforces strict Clean Architecture and Domain-Driven Design boundaries to mitigate architectural drift, and Keel, a strict AI-ready template for installable Python packages that applies the same boundaries in library form, demonstrated on an agent-engine domain.
