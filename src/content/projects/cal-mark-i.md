A physically simulated single-layer perceptron presented as a piece of cold-war era computing hardware, built with vanilla JavaScript, ES Modules, and CSS variables in a strict skeuomorphic design language. Inputs are an 8x8 grid of mechanical toggle switches, weights are 64 rotary potentiometers that physically rotate during training, and a physics-based galvanometer displays the discriminant sum in real time alongside a green-screen CRT terminal. There are no audio files in the project; every sound, from cooling fans to the drive motor and relays, is synthesized live with the Web Audio API. A live demo is hosted on GitHub Pages.
